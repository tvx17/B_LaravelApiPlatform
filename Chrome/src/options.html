Leseklar

Texte nach deinen Vorlieben lesen. Die Verarbeitung bleibt auf deinem Gerät.

Seitenverarbeitung

Stern, Doppelpunkt und Binnen-I werden für unterstützte Wortformen aufgelöst. Weiblicher Kontext bleibt weiblich, sonst wird die männliche Form verwendet. Die Kontextanalyse ist heuristisch und kann Fehler machen.

Bei der ersten Verarbeitung wird die Seite höchstens 1,5 Sekunden ausgeblendet. Sehr langsam geladene Inhalte können später sichtbar korrigiert werden. Code und editierbare Inhalte bleiben ausgenommen.

Eigene Regex-Regeln

Regeln laufen nach den Sprachregeln von oben nach unten. Ersatztexte unterstützen beispielsweise $1. Verwende einfache Muster: komplexe Regex können die Seite blockieren.

Zusätzliche Wortfamilien

JSON-Liste. „source“ ist der Stamm ohne Endung, zum Beispiel „Studierend“. Eigene Einträge überschreiben die gleichnamige Standardfamilie. „weak“ aktiviert Endungen wie „einen Studenten“.

Mitgelieferte Wortfamilien

    Vorschau

    Änderungen werden nach dem Speichern in geöffneten Seiten übernommen. Ausschalten stellt die ursprünglichen Texte wieder her, soweit die Website sie nicht inzwischen verändert hat.

    Keine Texte werden an einen Server übertragen. Diese Erweiterung ersetzt keine vollständige grammatische Analyse oder Prüfung der Barrierefreiheit.
